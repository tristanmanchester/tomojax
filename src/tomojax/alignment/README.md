# tomojax.alignment

Use `tj.align(scan, fit=..., grid=...)`. The [alignment guide](../../../docs/align-a-scan.md) explains how to choose parameters and inspect results. By default `fit="translations"` fits per-view lab-frame translations; `"center"`, `"tilt"`, `"roll"`, and `"rotations"` select additional parameter blocks.

On an unposed, unrolled axial parallel scan with a well-sampled half turn or full turn, `fit="center"` alone (with `method=None` and no grid, region, or joint settings) measures the rotation axis directly from the projections across the full detector width:

- On a half turn, it combines Fourier-slice edge sharpness, half-turn Fourier parity, and the sinusoidal first projection moment over up to 401 views, then refines the center to fractions of a native pixel using up to 16 opposing view pairs on their common illuminated support (closing an endpoint-exclusive half turn at the measured view spacing). Both stages account for stationary detector column structure and linear flat-field drift. `result.info["diagnostics"]` records `focus_px`, `binning`, `views`, and `pairs`.
- On a full turn (including offset-detector half-acquisition), it matches angular contrast across opposing view pairs over the whole detector width to locate the shared strip (falling back to half-turn focus if no positive-margin peak is found), recording `estimator="opposing-ray correlation"`, `pairs`, `rows`, and `overlap_px` in `result.info["diagnostics"]`. When the input file records no grid, `result.scan.grid` expands to the far detector edge while staying centered on the axis.

Both direct paths run on CPU, fit no working volume (`result.image` and `result.grid` are `None`), and record `method="sinogram-focus"`.

Explicit `method="joint"`, any joint solver option or `AlignConfig`, a `grid` or `region`, multi-parameter fits, and all other geometries share one private joint solver in `_joint`. When the joint solver fits `"center"` on an unposed, unrolled axial parallel scan, it initializes from the measured center above.

The joint solver estimates the volume and selected geometry parameters together. With the default `motion="independent"`, each view moves freely; with `motion="smooth"`, per-view translations follow a smooth-drift and robust-jump prior and per-view rotations couple to neighbors. Shared center and angle columns border the normal system. Exact Schur elimination gives the image update, and the backprojector is the exact transpose of the forward operator. Each working pixel traces one ray through its center, binned no coarser than a voxel. Native projections are read and binned in one sequential host pass: slabs whose pixels are all finite sum contiguous rows in `float64` before reducing columns and allocate no per-block weight array, while slabs with non-finite samples average observed pixels and allocate observation-fraction weights on first use. At large working levels the image solve shares whole view batches across visible GPUs and accumulates the transpose in acquisition order. Inside every step, each view's offset and vertical row ramp relative to the scan-wide mean level are profiled out so flux fluctuations do not mimic vertical motion. Every joint fit reports possible crossings in `info["disturbed_views"]`. Set `AlignConfig(exclude_views=...)` to omit reviewed half-open index ranges from the fit, record the retained input indices in `info["fit_views"]`, and interpolate excluded views' pose increments within each trajectory. Set `detector_columns` to `"fixed"`, `"transient"`, or `"both"` to estimate the corresponding column errors on the working projections. Set `image_tv_weight="coverage"` to weight volume differences by measured noise and local detector coverage. The returned `result.scan` carries the calibrated geometry and fitted per-view poses.

The line search compares each pose trial against the image-only trial at the same image step so an image improvement cannot pay for a worse pose. Per-view rotations carry a prior in radians (including their smooth components).

A pyramid level stops after two consecutive small geometry updates (following at least `min_iterations` steps) when damping is at or below its starting value. Step size is measured before line-search scaling.

Passing `checkpoint=DIR` to `tj.align` (or `--checkpoint DIR` to `tomojax align`, or `checkpoint` to the worker's and MCP server's `align`) saves each finished resolution level, the within-level volume, poses, damping, and step history at Gauss-Newton step boundaries, and the poses during refinement, so a killed fit resumes when the same call runs again. See [Resume a run after a kill](../../../docs/large-scans.md#resume-a-run-after-a-kill).

`tomojax.alignment.api` provides the crossing preflight `disturbed_views` and the pair-only opposing-view center estimator (`estimate_center`) and its diagnostic report (`estimate_center_report`), used by `tj.align(..., method="opposite-views")`.
