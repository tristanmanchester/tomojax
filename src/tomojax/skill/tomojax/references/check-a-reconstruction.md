# Check a reconstruction

1. Use `view` on the reconstruction to inspect all three planes. Check an off-center slice and a profile across a sharp edge. Report where you see blur, double edges, rings or streaks.
2. Use statistics to check the range and non-finite count. For a reference on the same grid, inspect a difference image. For a simulation, compare the volume with its phantom.
3. To compare solver settings, use `evaluate` on the source acquisition with the same held-out split for each candidate. Inspect slices for the leading settings at the same intensity limits. Report the score alongside the visible noise and resolution.
4. Read `truncation` in the reconstruction's summary (`recon.info["truncation"]` in Python: `edge_ratio`, `outside_fraction`, `interior_shift`, `radius`, `field_of_view_radius`, plus `outside_grid`, `data_model`, and `background_treatment` for iterative methods). `outside_fraction` estimates the share of attenuation that the cylinder continuation places beyond the detector, and different exteriors can produce the same measured rays. By default (`exterior="cylinder"`), `fourier`, `fbp`, and cone-beam FDK continue each detector row with a cylinder model, while `cgls`, `sirt`, `fista`, and `spdhg` subtract a coarse exterior estimate before solving and `mlem` adds its nonnegative estimate to predicted counts (pass `config: {"exterior": "zero"}` with an explicit `method` to fit the original data directly). Compare `interior_shift` with the contrast of interest, and keep in mind that non-cylindrical exteriors such as a square bar retain partial cupping and rim error.

Use a handle member, session array, `.npy` file or explicit `file.h5::/dataset` for an array. For saved TomoJAX volumes, pass the path directly to `view` or as the `volume` in `project`. The volume axes are `(z, y, x)`. Explicit datasets use their stored axis order.
